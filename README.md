# 조선 최고의 과학자 장영실을 만나요 🕰️

초등학생이 **진짜 장영실**이 어떤 사람이었는지 재미있게 알 수 있도록 만든, 짧은 애니메이션 같은 소개 페이지입니다.

## 배경

- 초등학교 5학년 딸이 영화 「천문: 하늘에 묻는다」(2019)를 보고 장영실을 인상 깊게 봤어요.
- 영화에는 실제 역사와 다르게 꾸민 부분이 있어서, **실제 역사 속 장영실**을 아이 눈높이에 맞게 알려 주려고 합니다.

## 만들 것

장면이 저절로 넘어가는 **1~2분짜리 HTML 페이지**를 만들어요. 영상처럼 보이게 합니다.

### 1. 캐릭터

- 새로 만든 장영실 캐릭터: 귀엽고 친근한 느낌, 조선시대 옷차림
- 장면에 따라 세종대왕 캐릭터도 등장해요.
- 영화 배우 얼굴이나 영화 장면을 따라 그리지 않아요.

### 2. 장면 구성

| 순서 | 장면 | 내용 |
|---|---|---|
| 1 | 오프닝 | 장영실 캐릭터가 인사하며 등장 |
| 2 | 노비 출신 소년 | 동래현(지금의 부산)의 관노 출신, 손재주가 뛰어났던 소년 |
| 3 | 재능을 인정받음 | 실력을 인정받아 궁에서 일하게 되고, 세종대왕이 벼슬을 줌 |
| 4 | 자격루 | 스스로 시각을 알리는 물시계 |
| 5 | 앙부일구 | 솥 모양의 해시계 |
| 6 | 측우기 | 비의 양을 재는 **세종 시대 발명품** |
| 7 | 영화 vs 실제 역사 | "영화와 실제 역사는 이게 달라요" 코너 |
| 8 | 마무리 | 장영실의 마지막 인사, 다시 보기 버튼 |

### 3. 말풍선

- 장면마다 캐릭터가 짧은 대사를 말해요.
- 한 말풍선에 1~2문장만 넣어서 아이가 읽을 시간을 줘요.

### 4. 영화 vs 실제 역사 코너

- "영화에서는 이랬지만, 실제 기록에는 이렇게 남아 있어요" 형식으로 비교해요.
- 기록이 없어서 **모르는 것은 모른다고** 알려 줘요.

## 규칙

- **파일 구성:** `index.html` 하나(CSS·JS 포함) + `images/` 폴더
- **캐릭터:** 장영실과 세종대왕은 코드(SVG/CSS)로 그린 귀여운 캐릭터
- **배경:** 실사 느낌의 장면 그림
- **핵심 유물:** 자격루·앙부일구·측우기는 실제 사진. 페이지 마지막에 사진 출처를 표시해요.
- **연도 강조:** 이야기 흐름에 맞춰 중요한 연도(1423년, 1434년, 1441년, 1442년)가 크게 나타나요.
- **말투:** 한국어, 초등학생이 읽기 쉬운 말투 (예: "~했어요", "~랍니다")
- **휴대폰:** 휴대폰 세로 화면에서도 잘 보여야 해요.
- **움직임:** 장면이 자동으로 넘어가고 캐릭터가 움직여요 (눈 깜빡임, 손 흔들기 등).
- **조작 버튼:** 재생/멈춤 버튼, 이전/다음 장면 버튼
- **길이:** 전체 1~2분 (장면당 약 8~15초)
- **역사 내용:** 확실한 사실만 넣어요. 확인이 어려운 내용은 빼거나 "~라고 전해져요"처럼 분명히 구분해요.

## 사실 확인 메모

역사 내용은 『세종실록』에 근거한 것만 써요.

- [x] **측우기:** 『세종실록』에는 측우기를 만든 사람이 세자(훗날 문종)로 기록되어 있어요. → "장영실이 만들었다"고 하지 않고 **"세종 시대 발명품"**으로 소개해요.
- [x] **출신:** 동래현(지금의 부산)의 관노 출신이라는 것만 넣어요.
- [x] **연도:** 1423년 상의원 별좌가 됨, 1434년 자격루·앙부일구, 1441년 측우기, 1442년 가마 사건. 이 연도를 장면 사이에 크게 보여 줘요.
- [x] **마지막 기록:** 1442년 세종이 탈 가마(안여)가 부서진 일로 벌을 받고 물러났고, 그 뒤의 삶은 기록이 없어요.
- [x] **영화와 다른 점:** "영화에서는 ~하게 그렸어요 / 실제 기록에는 ~만 남아 있어요" 형식으로 비교하고, 모르는 것은 "기록이 없어요"라고 써요.
